V67.2 FIFTH TRADING STRATEGY: MASTER PLAN (the Master Trade Plan card layer
             from the first tab now fires as an independent fifth signal source)
  V67.0 STRICT STOP-LOSS INVARIANT (the safety policy of this build)
- BUY positions: an existing protective stop is NEVER moved lower.
- SELL positions: an existing protective stop is NEVER moved higher.
- First protective stop on a stop-less position is always allowed.
- Broker minimum-distance (stops/freeze) rules may only cause a REFUSAL
  of a tighter stop - they never silently re-widen risk. The V65-and-
  earlier 'sl_widened_to_min_atr' widening behavior is removed.
- If the broker rejects a safe modification, the rejection is reported
  and the existing stop is retained; the SAME safe value is retried -
  never a risk-widening replacement. Broker retcode 10025 (NO_CHANGES)
  is treated as success.
- Enforced at both broker-facing choke points: modify_position()
  (terminal-initiated) and auto_modify_sl() (bridge ratchet/BE engine),
  in both the Windows bridge and the terminal's embedded engine copy.

FRESHNESS RECYCLE (V66.4 behavior carried forward)
- After 8h of uptime the bridge exits with code 81 at a quiet moment
  (never while an order is in flight). The supervisor relaunches a clean
  copy instantly. Tuned state lives on disk (apex_bridge\,
  browser_profile\) and is picked back up automatically.

SUPERVISOR CONSOLE (START_MORRYNET.bat / SUPERVISE_BRIDGE.ps1)
- LIVE bridge log in the window + mirrored to logs\bridge.log (rotated

- Single-instance: a healthy running bridge is detected and reused
  (stale listeners on 8765/8766 are cleared first).
- Terminal window (Edge --app with persistent browser_profile\, default
